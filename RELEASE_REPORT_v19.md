# Краткий отчет по версии v.19

Дата: 2026-08-28

## Статус версии

Версия `Excel Tab B24 v.19` подготовлена как serverless Marketplace-пакет для Bitrix24.

Архив для загрузки:

```text
dist app B24 zip/Excel Tab B24 v.19.zip
```

## Что исправлено

- Исправлено визуальное обрезание текста в ячейках после добавления новых столбцов: скрытая кнопка выбора CRM-поля больше не забирает постоянную ширину у каждой ячейки.
- Сохранены исправления v.17: добавление столбцов не должно терять значения, CRM-привязки и форматирование; экспорт `.xls` переносит формулы как формулы Excel; кнопка `Обновить поля` сжимает таблицу до заполненной области с минимумом 9x7; кегль применяется к нескольким выделенным ячейкам.
- Сохранено исправление v.18: стартовая видимая область таблицы рассчитана так, чтобы 9-я строка не скрывалась под горизонтальным скроллом.

## Проверки перед загрузкой

- `npm run lint` - успешно.
- `npm test` - успешно.
- Marketplace zip проверен: внутри только `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.

## Права Bitrix24 для текущей версии

- CRM (CRM)
- Placement / Встраивание приложений
- `user_basic`

Полный `user` и `user.userfield` для текущей версии не нужны.

## Что проверить на портале

- После загрузки именно `v.19` обычный текст в ячейках не обрезается после добавления столбцов.
- Все 9 базовых строк видны в стартовой области таблицы.
- Экспорт `.xls` открывается в Excel, строки и значения видны, формулы остаются формулами.
- `Обновить поля` обновляет CRM-привязанные значения и сжимает таблицу до заполненной области, но не меньше 9 строк и 7 столбцов.
- Кегль 11/13/15/18 пт применяется сразу к нескольким выделенным ячейкам.
