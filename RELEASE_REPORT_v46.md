# Release Report v46

Дата: 2026-09-16

## Статус

`Excel таблица в сделке и экспорт v.46` зафиксирована как релизная версия.

## Что вошло

- Удален индикатор количества полей сделки из нижней панели таблицы.
- Исправлено открытие новых сделок: лист в группе `Листы сделки` больше не подхватывает старые локальные данные до определения ID сделки.
- Добавлен отдельный временный ключ `excel-tab-b24-grid-pending-deal-v1`.
- ID сделки из текущего URL/referrer имеет приоритет над устаревшими placement-параметрами Bitrix24.
- Сохранено восстановление потерянных CRM-привязок старых листов по однозначному совпадению значения ячейки с текущим значением поля сделки.
- Неоднозначные совпадения одинаковых значений не восстанавливаются автоматически.
- Документация переписана под релизное состояние без устаревшего описания индикатора полей.
