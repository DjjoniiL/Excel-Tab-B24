# Краткий отчет по версии v41

Дата: 2026-09-14

Версия `Excel таблица в сделке и экспорт MVP Final v.41` подготовлена как serverless Marketplace-пакет для Bitrix24.

Архив для загрузки:

```text
dist app B24 zip/excel-tab-b24-v41.zip
```

## Что добавлено и улучшено

- Данные листов хранятся в Bitrix24 entity storage, поэтому листы сделки и общие листы воронки доступны пользователям с разных устройств.
- Добавлены две группы листов под таблицей: `Листы сделки` и `Общие листы`.
- Добавление листов ограничено 7 листами в каждой группе.
- Пустые дополнительные листы автоматически удаляются при закрытии карточки/вкладки и после синхронизации.
- После автоочистки листы перенумеровываются без пропусков: `Лист 1`, `Лист 2`, `Лист 3`.
- Нижняя панель вкладок расширена и финализирована: обе группы помещаются под таблицей в одну строку без внутреннего скроллинга.
- Сохранены одновременно ручной ввод в ячейки и выделение диапазона зажатой ЛКМ.
- Исправлен буфер обмена: при копировании и вставке диапазона не теряется первая ячейка.
- Исправлена работа с ячейками, где включен перенос текста: значение копируется и вставляется корректно.
- Добавлена защита от фоновой перерисовки активной ячейки во время ручного ввода.

## Проверки

- `npm test` - успешно.
- `npm run lint` - успешно.
- Marketplace zip проверен: внутри только runtime-файлы `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.

## Права Bitrix24

- CRM
- Placement / Встраивание приложений
- Entity / Хранилище данных приложения
- `user_brief`

Полные права `user`, `user_basic` и `user.userfield` для версии v41 не требуются.
