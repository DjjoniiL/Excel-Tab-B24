# Excel таблица в сделке и экспорт

Релизная версия: `v.46`

`Excel таблица в сделке и экспорт` - browser-only приложение для Bitrix24 Marketplace. Оно добавляет в карточку CRM-сделки вкладку `Excel таблицы` с компактной Excel-подобной таблицей, CRM-полями, формулами, форматированием, несколькими листами и экспортом заполненной области в Excel-compatible `.xls`.

Текущая ветка зафиксирована как релизная версия `v.46`.

## Что входит в релиз

- Вкладка сделки `CRM_DEAL_DETAIL_TAB` с рабочей таблицей 9x7 по умолчанию.
- Отдельные `Листы сделки` для конкретного `dealId`.
- `Общие листы` для воронки сделки по `categoryId`.
- До 7 листов в каждой группе.
- Автоудаление пустых дополнительных листов при закрытии/синхронизации, с перенумерацией оставшихся листов.
- Хранение состояния в Bitrix24 entity storage `exctabb24`; `localStorage` используется как локальный кеш и fallback.
- Добавление строк и столбцов кнопками `+`, а также через ПКМ по заголовку строки/столбца.
- Команды ПКМ: добавить 1 строку/столбец, добавить 4 строки/столбца, удалить строку/столбец.
- Перетаскивание одной строки или одного столбца за заголовок с переносом данных, размеров, форматирования, переноса текста, CRM-привязок и формул.
- Лимит рабочего листа: 3000 строк и 3000 столбцов.
- Выделение ячейки, диапазона, строк, столбцов и всей таблицы.
- Синяя внешняя граница выделенного диапазона и видимая синяя граница выбранной ячейки поверх заливки.
- Редактирование текста и чисел прямо в ячейках.
- Подстановка значений полей сделки через выпадающий список в активной ячейке.
- Обновление CRM-привязанных ячеек при загрузке и по кнопке `Обновить поля`.
- Восстановление потерянных CRM-привязок старых листов по однозначному совпадению значения ячейки с текущим значением поля сделки.
- Формулы с `+`, `-`, `*`, `/`, `%`, `^`, скобками и ссылками на ячейки.
- Сохраненные и последние формулы.
- Перенос текста, заливка, жирный, курсив, кегль 11/13/15/18 pt, горизонтальное и вертикальное выравнивание.
- Ручное изменение ширины столбцов и высоты строк.
- Копирование и вставка диапазонов между листами.
- Undo/redo и удаление выделения в блоке `Бэкап`.
- Экспорт заполненной области в `.xls` с сохранением формул, размеров, границ и форматирования.

## Важные исправления v46

- Из нижней панели полностью убран индикатор количества полей сделки.
- Новые сделки больше не подхватывают старый общий локальный лист до определения ID сделки.
- Временное состояние до определения сделки хранится по отдельному ключу `excel-tab-b24-grid-pending-deal-v1`.
- ID сделки из текущего URL/referrer имеет приоритет над устаревшими placement-параметрами Bitrix24.
- При обновлении CRM-полей приложение восстанавливает только однозначные потерянные привязки; одинаковые значения разных полей не привязываются автоматически.

## Хранение данных

Ключи первого листа сохраняют обратную совместимость:

- Лист сделки: `excel-tab-b24-grid-deal-v1-{dealId}`
- Общий лист воронки: `excel-tab-b24-grid-funnel-v1-{categoryId}`
- Временный лист до определения сделки: `excel-tab-b24-grid-pending-deal-v1`

Дополнительные листы получают суффиксы `-sheet-2`, `-sheet-3` и далее. Списки листов хранятся с суффиксом `-sheet-list-v1`.

## Формулы

Формула начинается с `=`.

Поддерживаются:

- ссылки `A1`, `B2`, `AA10`;
- числа;
- скобки;
- операции `+`, `-`, `*`, `/`, `%`, `^`.

В режиме редактирования пользователь видит исходную формулу. В обычном режиме показывается рассчитанный результат. Ошибочные и циклические формулы показывают `#ОШИБКА`.

При вставке, переносе строк/столбцов и удалении строк/столбцов формульные ссылки пересчитываются. Ссылки на удаленные ячейки превращаются в `#REF!`.

## Экспорт

Экспорт создает Excel-compatible HTML `.xls` через `Blob`.

В файл попадает только заполненная область. Минимальный пустой экспорт содержит одну ячейку, чтобы файл открывался корректно.

Сохраняются:

- формулы как Excel formulas;
- числовые значения как числа;
- текстовые значения как текст;
- ширины столбцов;
- высоты строк;
- границы;
- заливка;
- жирный, курсив, кегль и выравнивание.

- `install.html`
- `install.js`

- `index.html`

```bash
npm run lint

```

Сборка Marketplace zip:

```bash
npm run package
```

Финальный пакет:

```text
dist app B24 zip/excel-tab-b24-v46.zip
```

Скрипт сборки не перезаписывает существующий архив. Если `excel-tab-b24-v46.zip` уже есть, его нужно удалить вручную перед повторной сборкой этой же версии.
