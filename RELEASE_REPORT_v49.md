# Release Report v49

Дата: 2026-10-02

## Статус

`Excel таблицы в сделке и экспорт данных из CRM v.49` подготовлена как релизная версия.

- В режиме левого меню CRM список воронок перечитывается при открытии выбора воронки.

- Экспорт в Excel работает.
