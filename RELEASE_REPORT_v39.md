# Краткий отчет по версии v39

Дата: 2026-09-14

Версия `Excel таблица в сделке и экспорт MVP Final v.39` подготовлена как serverless Marketplace-пакет для Bitrix24.

Архив для загрузки:

```text
dist app B24 zip/excel-tab-b24-v39.zip
```

## Что добавлено и улучшено

- Добавлено общее хранение листов в Bitrix24 entity storage: данные листов сделки и общих листов воронки доступны пользователям на разных устройствах, `localStorage` оставлен как локальный кэш.
- Добавлены две группы листов под таблицей: `Листы сделки` для конкретной сделки и `Общие листы` для общей воронки.
- Добавлено создание дополнительных листов в каждой группе с ограничением до 7 листов.
- Добавлена автоматическая очистка пустых дополнительных листов при закрытии карточки/вкладки и после синхронизации с Bitrix24.
- После автоочистки листы автоматически перенумеровываются без пропусков: `Лист 1`, `Лист 2`, `Лист 3`.
- Нижняя панель листов переработана: две группы вкладок помещаются в одну строку под таблицей без внутреннего скроллинга.
- Сохранена ручная запись данных в ячейки и восстановлено выделение диапазона ячеек зажатой ЛКМ.
- Добавлена защита от фоновой перерисовки активной ячейки во время ручного ввода.
- Расширены проверки логики листов: лимит, определение пустого листа, автоочистка и сохранение непустых данных.

## Проверки

- `npm test` - успешно.
- `npm run lint` - успешно.
- Marketplace zip проверен: внутри только runtime-файлы `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.

## Права Bitrix24

- CRM
- Placement / Встраивание приложений
- Entity / Хранилище данных приложения
- `user_brief`

Полные права `user`, `user_basic` и `user.userfield` для версии v39 не требуются.
