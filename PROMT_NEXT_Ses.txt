Суть проекта:
Serverless-приложение для Bitrix24 Marketplace, которое встраивается как вкладка в карточку сделки. Вкладка показывает Excel-подобную таблицу: по умолчанию 9 строк и 7 столбцов. Пользователь может добавлять строки и столбцы, редактировать ячейки, выбирать поле сделки для вставки значения в текущую ячейку, выделять несколько ячеек, включать перенос текста, автоширину колонок, применять заливку и толщину шрифта, очищать выделенные ячейки, задавать формулы, сохранять формулы в список, удалять сохранённые формулы, применять сохранённую формулу к выбранной ячейке, протягивать формулы через Ctrl-выделение и экспортировать заполненную область таблицы в Excel-compatible `.xls`.

Ключевые правила проекта:
- Marketplace-версия должна быть serverless, без backend.
- OAuth/API ключи, portal credentials, `.env` и любые секреты не записывать в документацию, код, архивы и репозиторий.
- Для Marketplace создавать только новые versioned zip-архивы, старые архивы не перезаписывать.
- Архивы складывать в папку: `dist app B24 zip`.
- Название архива должно быть в формате: `Excel Tab B24 v.N.zip`.
- В Marketplace zip добавлять только runtime-файлы приложения, без документации, тестов, `.git`, `node_modules` и служебных файлов.
- Текущий состав Marketplace zip: `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.
- Перед сборкой или загрузкой Marketplace-версии обновить `PROJECT_SPECIFICATION.md`.
- Перед каждой загрузкой в Bitrix24 Marketplace обязательно написать пользователю список прав текущей версии.

Что уже сделано:
- Репозиторий инициализирован с нуля и подключен к GitHub.
- Создан browser-only каркас Marketplace-приложения.
- `install.html`/`install.js` перерегистрируют вкладку сделки через `placement.unbind` + `placement.bind`, чтобы вкладки не копились.
- `index.html`/`style.css`/`app.js` реализуют таблицу 9x7, добавление строк и столбцов, редактирование ячеек и выбор поля сделки.
- Данные таблицы разделены по сделкам через per-deal ключи `localStorage`.
- Ячейки, заполненные через выбор поля сделки, сохраняют привязку к полю и обновляются при открытии вкладки или ручной перезагрузке полей.
- Ручной ввод в ячейку снимает привязку к CRM-полю.
- Поповер выбора полей закрывается по крестику, Escape, клику вне окна, повторному клику по той же кнопке и после выбора поля.
- Исправлено CSS-скрытие поповера через `.field-popover[hidden] { display: none; }`.
- ID-поля сделки резолвятся в человекочитаемые значения там, где возможно: пользователи, контакт, компания, воронка, стадия.
- Добавлено выделение нескольких ячеек: одиночная ячейка, диапазон через Shift, добавление через Ctrl, выделение строки по номеру и столбца по букве.
- Добавлена кнопка `Выделить всё`.
- При выделении ячеек доступны действия `Добавить формулу`, `Удалить`, `Переносить текст`, заливка и толщина шрифта.
- Кнопка `Автоширина колонок` доступна всегда: без выделения применяет все колонки, с выделением — только выбранные.
- Добавлена кнопка `Экспорт в Excel`.
- Экспорт выгружает только заполненную область: до последней заполненной строки и последнего заполненного столбца, с учетом рассчитанных формул и форматирования.
- Добавлены формулы ячеек вида `=E4+B4`: поддерживаются ссылки на ячейки, числа, скобки и операции `+`, `-`, `*`, `/`.
- После ввода `=` клик по ячейке вставляет ее ссылку в активную формулу; повторные клики добавляют ссылки через `+`, а после введенного оператора ссылка добавляется после него.
- Enter в ячейке сохраняет введенное значение или формулу, выходит из режима редактирования и показывает рассчитанный результат.
- Добавлена кнопка `Добавить формулу`, которая появляется при выделении ячейки, открывает модальное окно сохранённых формул и применяет выбранную формулу к активной выбранной ячейке.
- В модальном окне справа можно ввести формулу и сохранить её в список; сохранённые формулы хранятся в `localStorage`.
- Ввод формул принимает только английские символы, цифры и знаки формул; английские буквы автоматически переводятся в верхний регистр, при русском вводе пользователь видит пояснение.
- У каждой сохранённой формулы есть кнопка удаления, список формул прокручивается внутри своего блока.
- Добавлена кнопка `Удалить` для выделенных ячеек: очищает данные, привязки к CRM-полям, заливку, толщину шрифта и перенос; при выделении более 18 ячеек показывает подтверждение.
- Ctrl-выделение от ячейки с формулой копирует формулу в новые ячейки с относительным смещением ссылок, включая Ctrl-клик по строке или столбцу.
- Внешний правый скролл приложения в iframe убран; скроллы при добавлении строк и столбцов остаются внутри области таблицы.
- Статус под заголовком показывает понятный активный режим: для сделки `Таблица сделки "..." из воронки ...`, для воронки `Общая таблица сделок. Воронка: ...`; нижние переключатели переименованы.
- Добавлен средний набор unit-тестов: grid helpers, deal ID extraction, storage state, field bindings refresh, reference formatting, selection helpers, arithmetic helpers, formula parsing/evaluation/reference shifting, Excel export trimming/escaping/styling.
