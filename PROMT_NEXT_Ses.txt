Суть проекта:
Serverless-приложение для Bitrix24 Marketplace, которое встраивается как вкладка в карточку сделки. Вкладка показывает Excel-подобную таблицу: по умолчанию 12 строк и 8 столбцов. Пользователь может добавлять строки и столбцы, редактировать ячейки, выбирать поле сделки для вставки значения в текущую ячейку, выделять несколько ячеек, включать перенос текста, автоширину колонок и экспортировать заполненную область таблицы в Excel-compatible `.xls`.

Ключевые правила проекта:
- Marketplace-версия должна быть serverless, без backend.
- OAuth/API ключи, portal credentials, `.env` и любые секреты не записывать в документацию, код, архивы и репозиторий.
- Для Marketplace создавать только новые versioned zip-архивы, старые архивы не перезаписывать.
- Архивы складывать в папку: `dist app B24 zip`.
- Название архива должно быть в формате: `Excel Tab B24 v.N.zip`.
- В Marketplace zip добавлять только runtime-файлы приложения, без документации, тестов, `.git`, `node_modules` и служебных файлов.
- Текущий состав Marketplace zip: `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.
- Перед сборкой или загрузкой Marketplace-версии обновить `PROJECT_SPECIFICATION.md`.
- Перед каждой загрузкой в Bitrix24 Marketplace обязательно написать пользователю список прав текущей версии.

Что уже сделано:
- Репозиторий инициализирован с нуля и подключен к GitHub.
- Создан browser-only каркас Marketplace-приложения.
- `install.html`/`install.js` перерегистрируют вкладку сделки через `placement.unbind` + `placement.bind`, чтобы вкладки не копились.
- `index.html`/`style.css`/`app.js` реализуют таблицу 12x8, добавление строк и столбцов, редактирование ячеек и выбор поля сделки.
- Данные таблицы разделены по сделкам через per-deal ключи `localStorage`.
- Ячейки, заполненные через выбор поля сделки, сохраняют привязку к полю и обновляются при открытии вкладки или ручной перезагрузке полей.
- Ручной ввод в ячейку снимает привязку к CRM-полю.
- Поповер выбора полей закрывается по крестику, Escape, клику вне окна, повторному клику по той же кнопке и после выбора поля.
- Исправлено CSS-скрытие поповера через `.field-popover[hidden] { display: none; }`.
- ID-поля сделки резолвятся в человекочитаемые значения там, где возможно: пользователи, контакт, компания, воронка, стадия.
- Добавлено выделение нескольких ячеек: одиночная ячейка, диапазон через Shift, добавление через Ctrl, выделение строки по номеру и столбца по букве.
- Добавлена кнопка `Выделить заполненные`.
- При выделении ячеек появляются действия `Переносить текст` и `Автоширина колонок`.
- Добавлена кнопка `Экспорт в Excel`.
- Экспорт выгружает только заполненную область: до последней заполненной строки и последнего заполненного столбца.
- Добавлен средний набор unit-тестов: grid helpers, deal ID extraction, storage state, field bindings refresh, reference formatting, selection helpers, Excel export trimming/escaping.
