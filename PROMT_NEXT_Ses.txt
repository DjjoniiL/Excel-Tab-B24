Суть проекта:
Нужно разработать serverless-приложение для Bitrix24 Marketplace, которое встраивается как вкладка в карточку сделки. Приложение показывает таблицу наподобие Excel: по умолчанию 12 строк и 8 столбцов. Под таблицей есть кнопка с плюсом для добавления строк, справа от крайнего столбца есть кнопка с плюсом для добавления столбцов. В каждой ячейке при фокусе доступна кнопка выбора поля сделки. При выборе поля сделки значение этого поля автоматически подставляется в текущую ячейку.

Ключевые правила проекта:
- Marketplace-версия должна быть serverless, без backend.
- OAuth/API ключи, portal credentials, .env и любые секреты не записывать в документацию, код, архивы и репозиторий.
- Для Marketplace создавать только новые versioned zip-архивы, старые архивы не перезаписывать.
- Архивы складывать в папку: dist app B24 zip
- Название архива должно быть в формате: Excel Tab B24 v.N.zip
- В Marketplace zip добавлять только runtime-файлы приложения, без документации, тестов, .git, node_modules и служебных файлов.
- Текущий состав Marketplace zip: install.html, install.js, install.css, index.html, app.js, style.css.

Обязательный цикл каждой итерации:
1. Выполнить git status --short.
2. Внести изменения.
3. Выполнить npm run lint.

6. Если собирается Marketplace-пакет, выполнить npm run package и проверить состав zip.
7. Сделать commit.

Перед каждой загрузкой приложения в Bitrix24 Marketplace обязательно напиши пользователю список прав, которые нужны текущей версии приложения.

Для текущей версии нужны права:
- CRM (CRM)

Для текущей версии НЕ нужны:
