Текущее состояние v29:
- Проект является serverless-приложением для Bitrix24 Marketplace без backend.
- Runtime-файлы приложения: `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.
- Marketplace zip должен включать только runtime-файлы, без документации, тестов, `.git`, `.env`, `node_modules` и служебных файлов.
- Последняя собранная Marketplace-версия: `C:\AI Project B24\Excel Tab B24\dist app B24 zip\Excel Tab B24 v.29.zip`.
- Последний коммит v29 смотри через `git log -1 --oneline` после обновления репозитория.
- В заголовке приложения должен отображаться номер версии: `Excel Tab B24 v.29`.
- Внешнего скроллинга приложения быть не должно вообще; скроллинг допускается только внутри области таблицы.
- После готовности нового zip пользователю нужно дать чек-лист ручной проверки на тестовом портале, желательно до 5 пунктов.

Что реализовано к v29:
- Вкладка сделки показывает Excel-подобную таблицу 9x7 по умолчанию, кегль 13 пт.
- Есть режим таблицы текущей сделки и общей таблицы воронки.
- Пользователь может добавлять строки и столбцы; добавление сохраняет значения, CRM-привязки и форматирование.
- Есть выделение одиночных ячеек, диапазонов через Shift, нескольких ячеек через Ctrl, строк, столбцов и всей таблицы.
- Есть перенос текста, автоширина колонок, заливка, жирный, курсив, кегль 11/13/15/18 пт.
- Есть блок `Выравнивание` после кнопки `Переносить текст`: верх, середина, низ, лево, центр, право.
- Выравнивание применяется к одной или нескольким выделенным ячейкам, видно в рабочей области, сохраняется и экспортируется.
- Автоширина колонок для многострочных ячеек считается по самой длинной строке, а не по сумме строк.
- Кнопка `Удалить` очищает данные, CRM-привязки, заливку, жирный, курсив, кегль, выравнивание и перенос; больше 18 ячеек требуют подтверждения.
- Формулы вида `=E4+B4` поддерживают ссылки на ячейки, числа, скобки и операции `+`, `-`, `*`, `/`.
- После ввода `=` клик по ячейкам добавляет ссылки в формулу.
- Enter сохраняет ввод/формулу и выходит из режима редактирования.
- Есть сохранённые формулы: добавление, удаление, прокрутка списка, применение к выбранной ячейке.
- При вводе `=` под ячейкой появляется список до 5 последних формул.
- Ctrl-выделение от ячейки с формулой протягивает формулу с относительным смещением ссылок.
- Экспорт `.xls` выгружает заполненную область таблицы: формулы как формулы Excel, числа как числа, ширины колонок, высоту строк, границы 1.5 pt, выравнивание и заданные заливки.
- Если заливок не было, экспорт не должен принудительно создавать белый фон.
- Кнопка `Обновить поля` обновляет CRM-привязанные значения и сжимает текущую таблицу до последней заполненной строки/колонки, но не меньше 9x7.

Обязательный цикл каждой итерации:
1. Выполнить `git status --short`.
2. Внести изменения.
3. Выполнить `npm run lint`.
4. Выполнить `npm test`.
5. Перед сборкой Marketplace-версии обновить документацию проекта и prompt следующей сессии.

Ключевые правила проекта:
- Marketplace-версия должна быть serverless, без backend.
- OAuth/API ключи, portal credentials, `.env` и любые секреты не записывать в документацию, код, архивы и репозиторий.
- Для Marketplace создавать только новые versioned zip-архивы, старые архивы не перезаписывать.
- Архивы складывать в папку: `dist app B24 zip`.
- Название архива должно быть в формате: `Excel Tab B24 v.N.zip`.
- Перед каждой загрузкой в Bitrix24 Marketplace обязательно написать пользователю список прав текущей версии.
