Помощь по приложению

После установки приложение автоматически добавляет вкладку «Excel таблицы в CRM» в карточку сделки.

Интерфейс рассчитан на ежедневную работу: открыть сделку, внести или пересчитать данные, при необходимости выгрузить результат в Excel. Пользователю не нужны специальные знания: достаточно уметь работать с карточкой сделки и обычной таблицей. Отдельная настройка приложения не требуется. Интеграция с внешними сервисами не используется.

Экспорт выполняется в формате .xls и включает заполненную область таблицы.

Чтобы начать работу:

  1. Откройте любую сделку.
  2. Перейдите во вкладку «Excel таблицы в CRM».

  3. На экране откроется уникальный лист этой сделки. Внизу доступны две группы листов: «Листы сделки» - только для текущей сделки, и «Общие листы» - для всей воронки продаж.

    Добавляйте новые листы, строки и столбцы кнопками «+» или через меню ПКМ по заголовкам. Строки и столбцы можно перетаскивать без потери данных.

  4. Используйте панель инструментов для форматирования текста, копирования и вставки данных. Диапазон можно выделить мышью, скопировать кнопкой или через Ctrl+C, а затем вставить на другой лист через Ctrl+V. Формулы добавляются через знак «=» или из сохраненных списков.

    В блоке «Бекап» доступны отмена и возврат действий.

  5. Если в CRM появились новые поля, нажмите «Обновить поля», чтобы они стали доступны для выбора в таблице.
  6. Нажмите «Экспорт в Excel», чтобы скачать заполненную таблицу в формате .xls.

Если нужна помощь, напишите в чат поддержки в этом окне.
