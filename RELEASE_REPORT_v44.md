# RELEASE REPORT v44

Дата: 2026-09-16

## База

v44 исправляет регрессии, найденные после v43.

Стабильная точка отката: v42. Пользователь подтвердил, что в v42 двойные области ушли, перетаскивание работает стабильно, формулы и параметры переносятся корректно.

## Изменения

- Статус нижней панели теперь показывает количество CRM-полей на текущем листе, а не общее количество доступных полей сделки.
- Добавление строк и столбцов больше не обрезает пустые крайние строки и столбцы.
- Лист работает как расширяемый канвас с ограничением 3000 строк и 3000 столбцов.
- Выделенный диапазон всегда получает синюю внешнюю границу.
- Если выбранная ячейка имеет заливку, синяя граница выбора остается видимой поверх заливки.
